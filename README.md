# Cactus Tours · vista previa

Prototipo del rediseño de cactustours.com.mx. Solo contiene el sitio compilado para revisión; no es el sitio oficial.

## Desarrollo local

Requiere Node.js y npm. Instala la dependencia y levanta el servidor de desarrollo:

```bash
npm install
npm run dev
```

Vite mostrará la dirección local, normalmente `http://localhost:5173`. El servidor entrega las páginas y recursos estáticos existentes; este repositorio no incluye el código fuente necesario para recompilar el sitio.
